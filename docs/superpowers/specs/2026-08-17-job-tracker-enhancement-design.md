# 岗位清单增强 设计文档

> 2026-08-17 · 方案 A（混合）

## 目标

把「岗位清单」从「4 类手动维护」升级为「9 类 + 每日拉新 + 过期清理 + 地区选择」。

## 架构

两块，明确分工：

1. **离线数据管线**（本地 Python 爬虫 + AI 清洗分类）→ 输出 `岗位清单.json`
2. **扩展岗位管理页**（展示 / 筛选 / 清理 / 拉取）

```
官网公告源 → 爬虫抓列表 → 筛最近7天 → AI 清洗分类 → 去重合并 → 岗位清单.json
                                                            ↓ 一键拉取
                                        扩展 jobs.html（9类/地区/过期/批量打开）
```

## 数据模型

岗位对象在现有字段基础上新增两个日期；`deadline` 开始真正抓取；`category` 改为 9 类：

| 字段 | 说明 |
|---|---|
| `deadline` | 报名截止日期 |
| `publishedAt` | 发布时间（新增，用于「最近一周」过滤） |
| `fetchedAt` | 抓取时间（新增，用于去重审计） |
| `category` | 下面 9 类 |

## 9 类分类

`公务员 / 事业编 / 教师 / 银行 / 国企 / 央企 / 军队文职 / 其它 / 私企`

边界规则（写入 AI prompt 与关键词兜底）：

- **教师** = 高校 / 职业学院 / 大专的教师、辅导员、行政
- **央企 ⊂ 国企**：中字头、国家电网 / 中石油 / 三大运营商等算「央企」，地方国资集团算「国企」
- **银行** = 各银行 / 农商行 / 城商行
- **公务员 / 事业编 / 军队文职** = 按来源站 + 关键词（人社厅/考试网→公务员·事业编，军队人才网→军队文职）
- **其它** = 兜底

## 爬虫（`crawler/`）

- 技术：`requests` + `beautifulsoup4`（`pip install requests beautifulsoup4`）
- 配置：`crawler/sources.json`（源清单，四川优先）
- 流程：抓公告列表（标题/链接/发布日期）→ 筛最近 7 天 → 新链接交给 AI 清洗分类 → 去重 → 写回 `岗位清单.json`
- AI：`crawler/config.json`（apiKey/baseUrl/model，**gitignored**）
- **反爬防护**：1–3 秒随机延迟、串行不并发、增量抓取（只抓新链接）、每天跑一次、遇 403/429 跳过并指数退避、正常 UA、军队/政府站再降一档频率

## 扩展增强（jobs-core / jobs.js / jobs.html）

| 功能 | 实现 |
|---|---|
| 一键拉取 | 重新导入最新 `岗位清单.json`（文件 或 配置的 URL），配置拉取数量 N |
| 删除过期 | 删 `deadline < 今天` 的岗位（确认后执行） |
| 选择地区 | 地区输入框改为下拉（四川城市）+ 可手动输入 |
| 9 类筛选 | 分类下拉改为 9 类 |
| 一键批量打开 | 打开配置的 BOSS/智联/考公雷达 网址列表 |
| 配置面板 | 拉取数量、默认地区、来源 URL、过期阈值，存 `jobConfig` |

## 实施顺序

1. 扩展数据模型 + 9 分类 + 过期判定（TDD，jobs-core + 测试）
2. 扩展 UI：9 分类筛选 + 地区下拉 + 删除过期
3. 旧数据 4→9 迁移（AI 重分类脚本）
4. 爬虫骨架 + 1 个源跑通
5. 扩展一键拉取 / 批量打开 / 配置面板
6. 爬虫铺满全部源 + Windows 任务计划

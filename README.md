# JobFill — 简历一键填写

在招聘平台（BOSS直聘、智联、前程无忧、LinkedIn 等）自动识别表单字段并填写简历信息的 Chrome 插件。

## 功能

- **扫描字段**：自动识别页面上的姓名、手机、邮箱、学历、工作经历等表单项，绿色高亮标记
- **一键填写**：将本地简历数据填入识别到的字段，蓝色高亮已填项
- **管理简历**：完整的简历信息管理页，支持多条教育/工作/项目/论文经历
- **导入/导出**：简历数据以 JSON 文件存储，换电脑时一键迁移

## 安装

1. 打开 Chrome，地址栏输入 `chrome://extensions/`
2. 右上角开启**开发者模式**
3. 点击「加载已解压的扩展程序」，选择本文件夹
4. 工具栏出现插件图标即安装成功

## 首次使用

```bash
# 复制模板文件，填入你自己的信息
cp resume-data.example.json resume-data.json
```

用文本编辑器打开 `resume-data.json`，按照模板格式填写个人信息。
也可以安装后直接在「⚙ 管理简历」页面填写，然后导出保存到本地。

## 使用流程

1. 打开招聘平台的投递页面
2. 点击右下角悬浮面板的「🔍 扫描字段」，查看识别到了哪些字段
3. 确认无误后点「✅ 开始填写」
4. 手动检查填写结果，提交申请

## 支持填写的字段

| 分类 | 字段 |
|------|------|
| 个人信息 | 姓名、性别、出生日期、手机、邮箱、微信、QQ、身份证、政治面貌、民族、国籍、籍贯、城市、地址、婚姻状况 |
| 求职意向 | 求职状态、类型、期望行业、岗位、城市、薪资、到岗时间 |
| 教育背景 | 学校、专业、学历、时间、学校类型、GPA、排名、荣誉、研究方向 |
| 工作/实习 | 公司、职位、地点、时间、薪资、公司规模、工作描述 |
| 项目经历 | 项目名、角色、时间、链接、描述 |
| 技能 | 技术技能、职场技能、证书、求职信 |
| 外语 | 语言种类、证书、分数、听说/读写能力 |
| 论文 | 标题、期刊、作者排名、状态、链接 |
| 其他 | 自我介绍、GitHub、个人主页 |

## 文件说明

```
JobFill/
├── manifest.json              # 插件配置
├── content.js                 # 注入页面的扫描/填写脚本
├── popup.html / popup.js      # 工具栏弹窗
├── options.html / options.js  # 简历管理页（完整编辑界面）
├── resume-data.example.json   # 简历模板（示例数据，可上传）
├── resume-data.json           # 你的真实简历数据（已加入 .gitignore）
└── icons/                     # 插件图标
```

## 隐私说明

- 所有数据**仅存储在本地浏览器**（`chrome.storage.local`）和本地文件，不上传任何服务器
- `resume-data.json` 已加入 `.gitignore`，不会被提交到 Git 仓库
- 如需备份，使用管理页的「⬇ 导出」功能下载 JSON 文件保存

## 换电脑

1. 旧电脑：管理页点「⬇ 导出」下载 `resume-data.json`
2. 新电脑：安装插件后，管理页点「⬆ 导入」加载该文件
